This folder contains example output files. They are generated from a made-up environment ("Contoso", see `tests/fake_azure.py`), not from a real tenant.  

| File | What it is |
| --- | --- |
| `output.drawio` | The draw.io diagram: a page per subscription and a network topology page |
| `subscription-page.png`, `network-topology.png` | Pictures of two of those pages |
| `output.xlsx` | The Excel overview |
| `output.json` | The raw data all other outputs are built from |
